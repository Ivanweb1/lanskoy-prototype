# Сюда кладём фотографии для дизайна главной.

## Чего не хватает

Квадрат 1600×1600, webp. Имена файлов жёстко прописаны в `design.html`:
пока файла нет, `design.js` прячет `<img>` и показывает подложку-монограмму,
как только файл лёг в папку — фотография появляется сама, разметку править не надо.

- `cat-lestnicy.webp` — Лестницы
- `cat-otoplenie.webp` — Отопление и кондиционирование

Требование к кадру, общее для всех `cat-*`: нижняя треть снимка — спокойная
светлая площадка (пол шоурума) без предметов. Товар стоит в верхних двух третях.
