# ТК «Ланской» — Ч/Б прототип главной

Кликабельный прототип главной страницы по итогам разбора ТЗ и брендбука. Чёрно-белый: цвет и типографика добавляются на этапе дизайна, сейчас на месте фирменной палитры — условные оттенки серого с комментарием в CSS, какой фирменный цвет каждый замещает.

## Экраны

- `index.html` — главная: шапка с мегаменю и поиском по сайту, hero, факты о комплексе, направления/категории, блок «Найти магазин» со схемой этажей, афиша, акции, блок «Аренда», раздел «Дизайнерам», журнал, бренды, подписка, футер

## Как смотреть

Тумблер **«Комментарии к блокам»** в чёрной панели сверху раскрывает пояснение под каждым блоком: что это, откуда взято (ТЗ / брендбук / добавлено при проектировании) и какие данные ещё не подтверждены.

Плейсхолдеры данных, которых пока нет (цифры, площадь, парковка и т.д.), помечены пунктирным подчёркиванием — их нельзя брать из брендбука, там два противоречащих друг другу макета.

## Источники стиля

- Логотип — настоящий локап заказчика (`logo.svg`), обесцвечен фильтром на время Ч/Б-этапа
- Паттерн-подложки (блок «Аренда», схема этажей) — приём из брендбука ТК «Ланской» v1.0/2026
- Шрифты временно системные (Georgia + гротеск) — фирменный шрифт уточняется у заказчика
