7. Найти магазин, а не бренды. По правке из ревью прототипа: блок логотипов брендов меняю на поиск по этажам — это и есть главный сценарий «где магазин X» из п. 6.12, вынесенный уже на главную, а не только на страницу схемы этажей. Каталог брендов никуда не делся, он доступен из шапки и со страницы «О комплексе». Поле здесь визуальное, как и остальные поля поиска в прототипе — переход на схему этажей с уже введённым запросом делает разработка.
