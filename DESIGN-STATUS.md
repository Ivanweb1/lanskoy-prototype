## Схема этажей — заметки

12.10 (позже): арендаторы 2 и 3 этажей (54 и 29 секций) — с tk-lanskoy.ru/map/ в floors-tenants.js, подключён только на design-floors (Ч/Б не тронут). Поиск и список — одной панелью «Магазины на этаже»: поле ищет по всем этажам (переключает этаж, подсвечивает секцию) и фильтрует список; на телефоне панель над планом, список виден только при запросе. Список — с прокруткой 280px (вариант «во всю высоту» Иван отверг).

12.10: floors.js общий с Ч/Б — правки дизайна только в design.js / design-pages.css поверх его разметки. Выбранная секция — тёмной карточкой (на телефоне — шторкой снизу с крестиком); подсказка у секций и значков — фирменная (navy + медная черта), вместо системной; номера секций 14px, в узких — уменьшаются по ширине; кнопки масштаба +/− (1–3×), на телефоне старт 2,5× с середины этажа, выбранная секция подводится в видимую часть; легенда: «Магазин / Секция / Выбрано» + значки без подписей; список магазинов во всю высоту, клик по строке возвращает к плану. Убрано как статусы вне ТЗ: «Свободных секций», «Занято», текст «Секция занята» в карточке → «Магазин уточняется».

## Категория — заметки

12.10 — принята. Кнопка «Все магазины» из шапки страницы убрана; «Все бренды» / «Весь журнал» — компактными кнопками по центру; у карточек без своего снимка временные фото. 12.10: фильтр по общему правилу — «Подкатегория ▾» слева, поиск по названию и № помещения справа, «Найдено N · Сбросить» только при фильтре; стена чипов и сортировка убраны. Первая страница — 12 карточек (из 28, пагинация на 3). Арендаторы и номера секций — с реальной схемы 1 этажа, подкатегории у них демо. Из подзаголовка убраны этажи. Бренды — марки категории «Декоративно-отделочные» из указателя брендов, с логотипами, строкой из 6; статьи — рубрика «Отделка и материалы». «Все бренды» / «Весь журнал» — кнопкой под блоком.

## Карточка магазина — заметки
