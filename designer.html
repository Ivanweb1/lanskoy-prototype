Поделиться

2. Контакты — через согласие, и это не перестраховка. На действующем сайте у дизайнеров открыто висят личные мобильные и почта на mail.ru. Это персональные данные физических лиц: по 152-ФЗ, на который ссылается п. 10.2, публиковать их можно только с согласия, и согласие должно быть зафиксировано. Поэтому в анкете нужен отдельный чекбокс «разрешаю публикацию контактов», а для тех, кто его не поставил, — кнопка «написать через комплекс», когда сообщение уходит администрации.
3. Кто поддерживает актуальность. Кабинетов у дизайнеров по п. 3.1 нет. Значит любое изменение — новый телефон, новые работы, уход из профессии — проходит через администрацию. Через год каталог будет наполовину неактуален, если не завести процедуру: например, раз в полгода рассылка с просьбой подтвердить данные, и карточки без подтверждения скрываются.
