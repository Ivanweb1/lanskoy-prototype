# ТК «Ланской» — дизайн-система (по главной `design.html`)

Эталон — дизайн главной. Каждая следующая страница собирается по этим правилам,
чтобы сайт читался одним целым. Ч/Б-прототипы (`index.html`, `shops.html` и т. д.)
не трогаем: они остаются источником структуры и текста.

## Как устроены файлы

| Файл | Что в нём |
|---|---|
| `style.css` | база Ч/Б-прототипа (сетка `.wrap`, сброс, структура компонентов). Подключается первым |
| `design.css` | токены бренда, шапка, мегаменю, мобильное меню, подвал, блоки главной |
| `design-pages.css` | компоненты внутренних страниц: шапка страницы, крошки, фильтры, карточки каталога и т. д. |
| `design.js` | тема, логотипы, липкая шапка, мегаменю, мобильное меню, появление блоков |
| `design-*.html` | дизайн-версии страниц. Структура и тексты — из одноимённого Ч/Б-прототипа, пояснения `.note` не переносятся |

Порядок подключения: `style.css` → `design.css` → `design-pages.css`.
После любой правки CSS/JS поднимать `?v=NN` во всех `design*.html`, иначе GitHub Pages отдаёт старый файл.
Ссылки шапки и подвала ведут на прототипы; `design.js` подменяет их на `design-*.html`, если дизайн-версия уже есть (словарь `DESIGN_PAGES`).

## Цвет

Один синий на весь сайт в обеих темах — `#011427` (замер по макету сайта, брендбук стр. 42).

| Токен | Значение | Где |
|---|---|---|
| `--b-navy` | `#011427` | текст светлой темы, фон тёмной, шапка, подвал |
| `--b-cream` | `#F6F4ED` | фон светлой темы, текст на синем |
| `--b-cream-2` | `#EAE7E1` | второй фон: плашки, подложки |
| `--b-copper` | `#C49A6C` | акцент: кнопки, иконки, линии, вторая строка заголовка |
| `--b-copper-ink` | `#8E6034` | медный **для мелкого текста на кремовом** (AA 4.87:1). На синем — обычный медный |
| `--g-navy` | `#000C1A → #0B2645`, 135° | градиентные синие секции |

В разметке использовать только семантические токены `--s-*` — они сами переключаются темой:
`--s-bg`, `--s-bg-2`, `--s-fg`, `--s-fg-soft`, `--s-accent`, `--s-accent-ink`, `--s-line`, `--s-line-strong`,
`--s-plate`, `--s-field-bg`, `--s-btn-fill-fg`. Своих hex в компонентах нет.

**Синие поверхности в светлой теме:** шапка, мегаменю, поиск, мобильное меню, блок «Аренда», подвал.
На них токены переопределяются локально (кремовый текст, медные линии) — так же делать новые синие блоки.

**Тёмная тема:** фон `#011427`, секции чередуют сплошной синий и `--g-navy`, линии медные полупрозрачные
(`rgba(196,154,108,.22)`), мелкий медный текст — обычный `--b-copper` (6:1 на синем).

## Типографика

- Заголовки — **Playfair Display 600**, капсом, `letter-spacing:.01em`, `line-height:1.06–1.15`.
  - H1 первого экрана: `clamp(42px, 4.85vw, 70px)`, вторая строка в `<em>` медным.
  - H1 внутренней страницы: `clamp(34px, 3.6vw, 54px)`.
  - H2 секции (`.sect__h2`): `clamp(28px, 3vw, 42px)`.
- Текст — **Montserrat**: основной 15–16px / 1.6, второстепенный 13–14px цветом `--s-fg-soft`.
- Надзаголовок (eyebrow): 11px, `letter-spacing:.22em`, капс, `--s-accent-ink`.
- Служебные подписи, кнопки, ссылки-действия: 11–12px, 600, `letter-spacing:.14em`, капс.
- Числа (счётчики, даты) — Playfair, медным или основным цветом.

## Геометрия

- Контейнер `--d-wrap: 1360px`, боковое поле `--pad` (20px на телефоне).
- Углы прямые: `border-radius:2px` у кнопок, полей, чипов; у карточек и фото — 0.
- Линии — 1px, `--s-line` (тонкая) или `--s-line-strong` (поля, рамки).
- Вертикальный ритм секций: `.sect{padding:88px 0}`, на телефоне 56px. Шапка секции: отступ 40px до контента.
- Сетка карточек — зазор 24px; «полотно» плиток (направления) — зазор 2px.
- **Паттерн-монограмму на внутренних страницах не использовать** (решение Ивана 06.10). Фоны — ровные.
- Диагональный срез — **только** в полноширинных баннерах, где кадр граничит с текстовой половиной
  (первый экран, «Аренда», «Найти магазин», шапки акции и события). У карточек и обычных фото среза нет.

## Компоненты

- **Кнопки:** `.dbtn` 56px, `--fill` — медная заливка с синим текстом, `--ghost` — медная обводка;
  наведение — подъём на 2px. Ссылка-действие `.dlink` — медный капс без подчёркивания, линия на наведении.
- **Поля:** высота 52–62px, рамка `--s-line-strong`, фокус — медная рамка, кнопка «Найти» встык медной заливкой.
- **Фильтры списков:** выпадающие списки «Категория ▾» слева, поиск справа в той же строке, счётчик под строкой. Стену чипов не делать (решение Ивана 06.10).
- **Списки:** 12 карточек, ниже «Показать ещё N» и «Показано 12 из M».
- **Служебные пояснения** о работе системы («снимется с публикации автоматически» и т. п.) посетителю не показывать.
- **Чипы:** 36px, рамка `--s-line`, наведение — медная рамка + `--s-plate`.
- **Чекбоксы:** свой квадрат 16px, рамка `--s-line-strong`; отмеченный — медная заливка с синей галкой.
- **Разделитель в перечнях:** круглая точка 3px цветом текста (как «Мебель • Свет • Декор», брендбук стр. 42). Ромбиков и своих значков не вводить.
- **Иконки:** линейные, медные, через `mask` (цвет из токена), 26–32px.
- **Карточки с фото:** кадр без рамки, при наведении фото `scale(1.05)`, заголовок — медным.
- **Шапка страницы:** крошки (11px капс, `--s-fg-soft`, текущая — основным цветом), H1, лид, справа — вкладки вида (`.dtabs`, афиша и галерея).
- **Переключатель вида каталога** (`.dviews`: магазины / категории / схема этажей): сегменты одной плашкой справа в шапке, низом на линии лида, 48px, иконка + капс 12px, активный — медная заливка. До 1200px — короткие подписи, до 1000px — под лидом, на телефоне — на всю ширину.

## Движение

- Плавность `--d-ease: cubic-bezier(.22,.61,.36,1)`, переходы .2–.35s.
- Блоки появляются при прокрутке (`.js-rv` / `.is-in`), уважаем `prefers-reduced-motion`.

## Адаптив

Проверять на 1440, 1100, 760, 375, 320. Без горизонтальной прокрутки.
Меню уходит в бургер на 760px. Сетки карточек: 4 → 3 → 2 → 1 (одна колонка — на 360 и уже).
